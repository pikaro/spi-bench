Static task allocation work: repo-owned TaskController tasks now default to ESP-IDF static creation with exact-size owner storage from include/StaticConfig/Stacks.hpp. No pool or #ifdef feature switches. StaticConfig::TaskStacks::defaultTaskStorageStatic is the constexpr all-task default; TaskController::Config::allocation can still choose Static/Dynamic at runtime, and TaskController::StaticTaskStorageEnabled<Owner> can be specialized for constexpr storage opt-out. System/library tasks remain outside this abstraction and are reported as Dynamic in monitoring. Media currently fails to link with default static reservations: .dram0.bss overflow by 60328 bytes; bin/task-stacks media reports 40960 bytes configured task stacks, with additional static ring-buffer/TCB/alignment contributing.
