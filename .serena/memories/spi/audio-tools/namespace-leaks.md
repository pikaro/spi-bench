AudioTools on `env:media` leaks names broadly when `USE_AUDIOTOOLS_NS` is enabled, and its ESP-IDF `NoArduino.h` path also has a global `using namespace std;`. Put `-DUSE_AUDIOTOOLS_NS=0` in `platformio.ini` `build_flags`, not `board_build.cmake_extra_args`; the latter is only a CMake cache arg and does not define the preprocessor macro for clangd/compilation. Avoid generic project globals such as `Pins` or `hash` in headers included with AudioTools.
