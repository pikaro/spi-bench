LittleFS images are intentionally built from `data/<env>/littlefs` via `[platformio] data_dir = ${PROJECT_DIR}/data/${PIOENV}/littlefs`. Keep unrelated per-device data outside that subtree; `data/media/test.wav` is larger than the 4 MiB board's `0x1E0000` LittleFS partition and will make `buildfs` fail if included. Runtime validation uses `/ls` and boot calls `Totem::FileSystem::detail::logFileSystemContents()` from `CoreSetup`.
