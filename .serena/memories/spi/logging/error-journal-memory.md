The logging error journal is intentionally RAM-sensitive, especially on `env:media` (ESP32 original with Bluetooth/WiFi). A full 5-slot journal that duplicates `LogRecord` (128-byte messages) in all history/trailing/error slots overflowed media DRAM by ~1480 bytes. Keep journal context copies compact or optional behind `LOGGING_ERROR_JOURNAL_ENABLED`; build `media` when changing journal storage shape.
