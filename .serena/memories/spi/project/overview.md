Embedded C++23 library and application stack for ESP32-class microcontrollers built with PlatformIO on top of ESP-IDF. Day-to-day work targets env:master. Codebase is organized around public service headers in include/Services, reusable base layers in include/Base, subsystem backends in include/*Backend, static config in include/StaticConfig, generated wire code in include/Generated/Wire, and environment entrypoints under src/master, src/slave, and src/listener.
