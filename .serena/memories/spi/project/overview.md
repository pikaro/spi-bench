Embedded C++23 codebase for ESP32-class microcontrollers built with PlatformIO on ESP-IDF. Active routine target is env:master. Architecture is header-heavy with public services under include/Services, reusable foundations under include/Base, subsystem backends under include/*Backend, compile-time config under include/StaticConfig, generated wire code under include/Generated/Wire, and env-specific roots under src/master, src/slave, src/listener. Validation is primarily by successful compilation and code review; no host-side unit-test harness is present.
