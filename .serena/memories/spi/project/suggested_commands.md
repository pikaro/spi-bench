Primary commands: `bin/build -e master` to build the active target, `pio run -e master -t compiledb` to emit the compilation database, `make wire` or `make wire PIO_ENV=master` to regenerate wire support code, `make wire-clean` to remove generated wire output, `bin/objsizes master` and `bin/objsize master '<symbol>'` to inspect object sizes, and `bin/gdb master` to start GDB with the correct firmware.
