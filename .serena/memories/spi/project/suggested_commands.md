Primary commands: `bin/build -e master` to build the active target; `pio run -e master -t compiledb` to emit a compilation database; `bin/objsizes master` to list the largest symbols in the master build object; `bin/objsize master <symbol>` to inspect layout/member sizes for a symbol such as `commandController`; `make wire` or `make wire PIO_ENV=master` to generate wire support code; `make wire-clean` to remove generated wire output. Firmware artifact is `.pio/build/master/firmware.elf`.
