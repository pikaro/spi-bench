StatusLed first implementation uses `include/StatusLed/` with a global `StatusLedService` bound from `CoreSetup`. WS2812B output is driven by a tiny ESP-IDF RMT backend (`detail/platform/RmtWs2812.hpp`) rather than LEDC, because LEDC cannot produce the WS2812 timed one-wire bitstream. The component avoids a dedicated task; `CoreSetup::work(nowMs)` drives cycling and state changes only mark atomic masks/dirty state. Configured status LEDs: master/gpu use `Pin::StatusLed`, media uses local `Pin::GPIO16`, io is explicitly disabled until it has RGB hardware or a future single-color backend.
