StatusLed now supports two configured output backends: the existing `OutputBackend::RmtWs2812` using top-level `Config::pin` and `Config::colorOrder`, and `OutputBackend::SplitRgbGpio` using `Config::splitRgbGpio` (`red`, `green`, `blue`, `activeHigh`). The split backend lives in `include/StatusLed/detail/platform/SplitRgbGpio.hpp` and drives plain GPIO outputs: any nonzero RGB channel is on, zero is off, with polarity controlled by `activeHigh`. `env:ai`/Arduino Nano ESP32 config uses `Pin::LED_RED`, `Pin::LED_GREEN`, `Pin::LED_BLUE` with `.activeHigh = false`. Existing master/media/gpu configs remain on the default WS2812 backend and keep their existing `.pin` shape.
