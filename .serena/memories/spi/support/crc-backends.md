Shared CRC helpers live under `include/Platform/Crc/` because both wire transports and PubSub serialization use them. Layout follows the project PlatformSelect pattern: `Platform/Crc/PlatformSelect.hpp` selects the active backend, `Platform/Crc/platform/PlatformGeneric.hpp` preserves the CRCpp implementation for benchmarking/fallback, and `Platform/Crc/platform/PlatformESP32.hpp` wraps ESP-IDF ROM helpers. Public include is `Platform/Crc/Facade.hpp`. `Totem::Platform::Crc::Platform` aliases `PlatformESP32` on `PLATFORM_ESP32` and `PlatformGeneric` otherwise; `Totem::Platform::Crc::Generic` remains available for comparison. CRC-8 must preserve CRCpp `CRC_8` / CRC-8-SMBus semantics: `~esp_crc8_be(0xff, data, len)`. CRC-32 preserves CRCpp `CRC_32` semantics with `esp_crc32_le(0, data, len)`. Hot call sites in SPI PDU, RS485 PDU, and PubSub SerDe use `Totem::Platform::Crc::Platform`.
